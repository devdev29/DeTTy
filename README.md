# DeTTy 🐍

A lightweight, decorator-based WSGI-compliant HTTP framework for Python.

> **Note**: This README was generated by an AI agent (Claude).

## Features

- **WSGI Compliant** - Works with any WSGI server (gunicorn, uwsgi, etc.)
- **Decorator-based routing** - Register routes with simple decorators
- **Path parameters** - Extract values from URL paths using `{param}` syntax
- **Type-safe parameter injection** - Automatic validation with Pydantic
- **Header & Body extraction** - Use `Annotated` types to inject request data
- **Response object access** - Full control over HTTP responses
- **Gzip compression** - Automatic response compression when client supports it
- **Built-in development server** - Simple server for local testing

## Quick Start

```python
from app.detty import DeTTy

app = DeTTy()

@app.register('/', 'GET')
def home():
    return "Hello, World!"

if __name__ == "__main__":
    app.run()
```

Run your server:
```bash
python -m app.main
```

The server starts on `http://127.0.0.1:4221`

## Examples

### Basic Route

```python
@app.register('/', 'GET')
def home():
    return "Welcome to DeTTy!"
```

### Path Parameters

Extract values directly from the URL path:

```python
@app.register('/echo/{message}', 'GET')
def echo(message: str):
    return message

@app.register('/users/{user_id}/posts/{post_id}', 'GET')
def get_post(user_id: int, post_id: int):
    return f"User {user_id}, Post {post_id}"
```

```bash
curl http://localhost:4221/echo/hello
# Response: hello

curl http://localhost:4221/users/42/posts/7
# Response: User 42, Post 7
```

### Header Parameters

Access request headers using `Annotated` with `Header`:

```python
from typing import Annotated
from app.models import Header

@app.register('/user-agent', 'GET')
def get_user_agent(ua: Annotated[str, Header(header_name='User-Agent')]):
    return ua
```

```bash
curl -H "User-Agent: MyClient/1.0" http://localhost:4221/user-agent
# Response: MyClient/1.0
```

### Body Parameters

Handle POST request bodies:

```python
from typing import Annotated
from app.models import Body

@app.register('/files/{filename}', 'POST')
def create_file(filename: str, content: Annotated[str, Body()]):
    with open(f'/tmp/{filename}', 'w') as f:
        f.write(content)
    # Returns 201 Created by default for POST
```

```bash
curl -X POST -d "Hello, file!" http://localhost:4221/files/test.txt
```

### Custom Response Control

Inject the `HttpResponse` object for full control:

```python
from app.http_response import HttpResponse
from app.http_constants import HttpStatus

@app.register('/files/{filename}', 'GET')
def get_file(filename: str, response: HttpResponse):
    file_path = f'/tmp/{filename}'
    
    if not os.path.exists(file_path):
        response.status_code = HttpStatus.NOT_FOUND.code
        response.reason_phrase = HttpStatus.NOT_FOUND.phrase
        return response
    
    with open(file_path, 'rb') as f:
        response.response_body = f.read().decode('ASCII')
        response.media_type = 'application/octet-stream'
    
    return response
```

### Returning Different Types

DeTTy automatically infers the `Content-Type` based on what you return:

```python
# Returns text/plain
@app.register('/text', 'GET')
def text_response():
    return "Plain text"

# Returns application/json
@app.register('/json', 'GET')
def json_response():
    return {"message": "Hello", "count": 42}

# Returns application/octet-stream
@app.register('/binary', 'GET')
def binary_response():
    return b'\x00\x01\x02'
```

## Running with Options

### Development Server

The built-in development server is suitable for local testing:

```python
# Default: runs on 127.0.0.1:4221
app.run()

# Custom host and port
app.run(host='0.0.0.0', port=8000)

# Disable request logging
app.run(verbose=False)
```

**Note**: The development server is single-threaded and should only be used for testing. For production, use a production-grade WSGI server.

## Production Deployment

DeTTy is WSGI-compliant and works with any WSGI server.

### With Gunicorn

```bash
# Install gunicorn
pip install gunicorn

# Run with 4 worker processes
gunicorn -w 4 -b 0.0.0.0:8000 app.main:app

# With automatic reloading (development)
gunicorn --reload -b 0.0.0.0:8000 app.main:app
```

### With uWSGI

```bash
# Install uwsgi
pip install uwsgi

# Run
uwsgi --http :8000 --wsgi-file app/main.py --callable app --processes 4
```

### With Waitress (Windows-friendly)

```bash
# Install waitress
pip install waitress

# Run
waitress-serve --host=0.0.0.0 --port=8000 app.main:app
```

### WSGI Compatibility

The DeTTy instance is directly WSGI-callable:

```python
# app/main.py
from app.detty import DeTTy

app = DeTTy()

@app.register('/', 'GET')
def home():
    return "Hello, World!"

# This 'app' instance can be used with any WSGI server
# gunicorn app.main:app
# uwsgi --wsgi-file app/main.py --callable app
```

## Compression

DeTTy supports gzip compression. When a client sends `Accept-Encoding: gzip`, the response body is automatically compressed.

```bash
curl -H "Accept-Encoding: gzip" http://localhost:4221/echo/hello --compressed
```

Supported encodings are defined in `http_constants.py`:

```python
SUPPORTED_CONTENT_ENCODINGS: set[str] = set(['gzip', 'deflate', 'br'])
```

```
├── exceptions.py      # Custom exceptions
└── main.py            # Example application
```

## Architecture

DeTTy follows a clean separation of concerns:

1. **Application Layer** (`application.py`) - Core framework logic independent of server implementation
2. **WSGI Layer** (`wsgi.py`) - Adapts the application to WSGI interface
3. **Server Layer** (`server.py`) - Development server using Python's wsgiref
4. **Entry Point** (`detty.py`) - Main class that ties everything together and is WSGI-callable

This architecture allows DeTTy to work with any WSGI server while maintaining clean, testable code.
